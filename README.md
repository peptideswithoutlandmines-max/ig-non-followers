# ig-non-followers

Simple mobile page listing Instagram accounts that **@tshell7** follows who do not follow back.

Tap a username → opens their Instagram profile.

## Open now
Open `index.html` on your phone, or after GitHub Pages is on:
https://peptideswithoutlandmines-max.github.io/ig-non-followers/

## Refresh
Tap **Refresh** to ping the CoS routine `IG non-followers refresh`. On first use you’ll paste the webhook URL from that routine. It is stored in this browser only (`localStorage` key `igNonFollowersWebhookUrl`) — never commit the URL or any secret into the repo. Use **Change webhook** to update or clear it.
